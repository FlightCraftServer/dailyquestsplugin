/dq - открыть меню заданий
откроется меню из трёх заданий
можно выполнить все 3 задания, но начать можно только 1 одновременно
при получении прогресса будет писать в чат
как только задание выполнится, нужно написать /dq и сдать квест
награда теперь в монетах

/dq leaderboard - таблица лидеров
в чат напишет кто больше всего выполняет ежедневных заданий
топ 3 игрокам даётся небольшой бонус при получении награды

/dq time - время до сброса
напишет в чат сколько времени осталось до выдачи новых заданий (сброс в 00:00 по мск)


/dq reroll ник - админская команда чтобы рерольнуть игроку квесты
